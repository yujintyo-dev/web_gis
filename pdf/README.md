# pdf フォルダ

ポップアップからダウンロードさせるPDF(資料)を置くフォルダです。
このフォルダの中身は、そのまま公開サイトの `pdf/` にコピーされます(この README は公開されません)。

## 置き方の例

属性の値をファイル名にします。

```
pdf/
  用途地域/
    1.pdf    ← YoutoCode が 1 の図形をクリックしたときに出るPDF
    2.pdf
    …
```

管理画面でレイヤーを選び、「PDF資料」タブの「ファイルの場所」に `pdf/用途地域/{YoutoCode}.pdf` と書くと、
クリックした図形の YoutoCode の値に合ったPDFへのリンクが、ポップアップに表示されます。
**ファイルが無い図形には、リンクは出ません。**

## 注意

- ファイル名は、属性の値と全角/半角・大文字/小文字(`.pdf` と `.PDF`)まで一致させてください
- 1ファイル100MBまで(Webからのアップロードは25MBまで)。公開サイト全体で1GBまでです
- Publicリポジトリに置いたファイルは、誰でも閲覧・ダウンロードできます。公開してよい資料だけを置いてください
