管理画面 公開サイトを開く

config.json をダウンロードしました

設定を公開サイトに反映するには、ダウンロードした config.json を GitHub のリポジトリにアップロードしてください。

  1. GitHub でリポジトリを開く
  2. 「Add file」→「Upload files」を押す
  3. ダウンロードした config.json をドラッグ&ドロップする(ファイル名は config.json のまま。「config (1).json」などになっていたら名前を直す)
  4. 「Commit changes」を押す → 数分後に公開サイトへ反映されます(Actions タブで進み具合を確認)

※ 他の人が同時に管理画面で編集していると、後からアップロードした方の内容で上書きされます。
