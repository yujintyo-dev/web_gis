# img フォルダ

注意事項(利用規約ページのタブ)に入れる画像を置くフォルダです。
このフォルダの画像は、そのまま公開サイトの `img/` にコピーされます(この README は公開されません)。

- 使える形式: png / jpg / jpeg / gif / webp(SVG は安全のため使えません)
- 画像を置いて Commit すると、数分後に管理画面の「利用規約・注意事項・案内帯」→ 本文の「画像を挿入」で選べるようになります
- 本文には `![画像の説明](img/ファイル名.png)` の形で入ります(1行に1つ)
- 画面に合わせて自動で縮小されますが、読み込みを軽くするため、横幅1200px程度・1枚数百KB以内がおすすめです
- 外部サイトの画像は使えません(閲覧者の情報が外部に送られるのを防ぐため)
